# ChannelIndex (tgAtlas)

A read-only HTTP API over public Telegram data: resolve @usernames to numeric IDs, read channel size/description, walk post history with per-post views/forwards, pull Telegram similar-channel recommendations, and search the public directory. No phone number or MTProto session required. Auth via RapidAPI gateway headers. Also ships channelindex-mcp, a local/stdio MCP server wrapping the same REST API.
